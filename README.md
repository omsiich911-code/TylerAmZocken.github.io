# OMSI Projects – Webseite

Eine responsive, dunkle Startseite für ein OMSI-2-Projekt. Sie nutzt nur HTML, CSS und JavaScript – keine zusätzlichen Pakete.

## Lokal öffnen

1. ZIP-Datei entpacken.
2. `index.html` im Browser öffnen.
3. Für die Bearbeitung eignet sich Visual Studio Code.

## Anpassen

- Texte, Projektkarten und Links: `index.html`
- Farben, Layout und responsive Darstellung: `style.css`
- Mobiles Navigationsmenü und Jahreszahl: `script.js`

Suche in `index.html` nach `https://www.youtube.com/` und `https://discord.com/`, um die Platzhalter durch deine eigenen Links zu ersetzen. Aktualisiere auch Projektnamen, Neuigkeiten und den Seitennamen.

## Kostenlos veröffentlichen mit GitHub Pages

1. Erstelle ein Konto auf https://github.com/.
2. Erstelle ein neues Repository, zum Beispiel `omsi-projects`.
3. Lade `index.html`, `style.css`, `script.js` und optional `README.md` ins Repository hoch.
4. Öffne **Settings → Pages** und wähle als Quelle den Hauptbranch (`main`) und den Ordner `/(root)`.
5. GitHub zeigt dir die veröffentlichte Adresse an, sobald die Veröffentlichung abgeschlossen ist.

## Eigene Domain

1. Registriere eine verfügbare Domain bei einem Domainanbieter.
2. Öffne in GitHub Pages den Bereich **Custom domain** und trage die Domain ein.
3. Folge den dort angezeigten DNS-Anweisungen beim Domainanbieter.
4. Aktiviere HTTPS, sobald GitHub die Domain geprüft hat.

DNS-Einträge unterscheiden sich je nach Domain und Hosting-Konfiguration. Verwende die aktuellen Anweisungen deines Hosters und kopiere keine beliebigen Einträge aus fremden Anleitungen.

## Vor dem Veröffentlichen

- Eigene Projektbilder und Texte verwenden oder die Nutzungsrechte prüfen.
- Keine fremden Mods ohne Erlaubnis erneut hosten; besser zur Originalquelle verlinken.
- Kontakt-, Datenschutz- und Impressumsangaben prüfen, wenn sie für dein Angebot erforderlich sind.
- Die Seite ist ein Fanprojekt und keine offizielle OMSI-2-Webseite.
